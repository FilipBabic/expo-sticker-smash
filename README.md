# Completed Expo Application 👋

This is a mobile application built by following the official [Expo](https://expo.dev) tutorial. The project is fully completed and ready to run on both Android and iOS devices.

## 🚀 How to Run the Project Locally

Follow these steps to set up and start the application on your machine:

### 1. Clone the repository

```bash
git clone https://github.com
cd YOUR-REPO-NAME
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the Expo development server

```bash
npx expo start
```

---

## 📱 How to Test the App

After running `npx expo start`, use the terminal menu or the browser interface at `localhost:8081` to open the app via:

- **Expo Go**: Scan the QR code displayed in the terminal using your phone's camera (iOS) or the Expo Go app (Android).
- **Android Emulator**: Press `a` in the terminal (requires Android Studio).
- **iOS Simulator**: Press `i` in the terminal (requires macOS and Xcode).

---

## 🛠️ Project Structure

This project utilizes **Expo Router** (file-based routing). The main codebase is organized as follows:

- `/app` - Contains the screens and routing logic of the application.
- `/components` - Reusable UI components built during the tutorial.
- `/assets` - Images, icons, and fonts used throughout the app.
